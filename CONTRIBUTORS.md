## How to Contribute
1. **Fork the Repository**: Create your own copy of the project.
2. **Feature Branching**: Always create a new branch for your changes:
   - `feature/your-feature-name` for new features.
   - `fix/your-bug-fix` for bug fixes.
   - `docs/your-doc-update` for documentation.
3. **Conventional Commits**: Use clear commit messages:
   - `feat: add new price prediction model`
   - `fix: resolve login timeout`
   - `docs: update deployment steps`
4. **Pull Requests**: Submit a PR to the `develop` branch. Ensure your PR description clearly explains the changes and references any related issues.
5. **Code Review**: At least one maintainer must review and approve the PR before it is merged into `develop`.

## Code of Conduct
Please be respectful and professional in all communications.
